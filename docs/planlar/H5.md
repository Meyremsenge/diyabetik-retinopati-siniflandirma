```python
def pick_gallery_rows(predictions: pd.DataFrame, seed: int = 42) -> pd.DataFrame
    # Girdi: val_predictions.csv (sütunlar TEKNIK §7: image_id, y_true, y_pred, prob_0..prob_4)
```

CLI (mevcut `--image` moduna ek; ikisi karşılıklı dışlayan):
